# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within Easy Cartoonify, please do not disclose it via public GitHub issues.

Instead, please report it privately to the maintainers or open a GitHub Security Advisory. We will acknowledge receipt within 48 hours and coordinate a fix and release disclosure.
